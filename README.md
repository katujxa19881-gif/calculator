# Калькулятор стоимости изделия

Интерактивный виджет для расчёта себестоимости, цены и рентабельности изделия.
Один html-файл без внешних зависимостей — открывается двойным кликом или вставляется в блок Т123 на Tilda.

Модель расчёта повторяет шаблон «Калькуляция_матрица» (лист Excel) — сверено до копейки на контрольном примере.

## Что считает

Блоки ввода:

* **заказ** — изделие, партия, наценка на себестоимость, целевая цена за штуку, НДС, логистика на заказ
* **подготовка производства** — строки «что делаем / исполнитель / время на заказ / материалы»;
  время вводится на весь заказ (сек, мин или часы), калькулятор сам разносит его на партию
* **оснастка** — только стоимость (на заказ или на 1 шт); производственные коэффициенты на неё не начисляются
* **выпуск изделий** — переключатель: общая трудоёмкость (сек/шт) либо разбивка по этапам (SMT, THT, FAS, монтаж, сборка, тестирование, упаковка, загрузка ПО)
* **материалы** — норма расхода на 1 шт × цена за единицу

Итоги показываются укрупнённо: разовые затраты по заказу (подготовка + оснастка + логистика)
и серийные затраты (материалы + выпуск), каждый блок раскрывается по клику.
Ниже — полная себестоимость, цена без НДС, скидка заказчику, прибыль, маржинальность,
рентабельность к себестоимости и цена с НДС. Всё дублируется «на партию» и «за штуку».

Внутренняя структура затрат (ФОТ, амортизация, ОПР, ОХР) в интерфейсе не раскрывается —
накладные распределяются по блокам пропорционально, поэтому сумма блоков равна полной себестоимости.

## Тарифы

Коэффициенты расчёта не зашиты в интерфейс — они передаются **кодом тарифов** вида `CTS1-…`:

1. кнопка «тарифы» → «служебный режим» → пароль → редактор ставок;
2. правишь значения (соответствуют листу «Константы_и_ставки») и жмёшь «сгенерировать код»;
3. отправляешь полученную строку коллегам — они вставляют её один раз в окне «тарифы».

Код сохраняется в браузере; при смене ставок достаточно прислать новую строку.
Пока код не введён, калькулятор показывает предупреждение и не считает стоимость.

Пароль служебного режима хранится в коде в виде SHA-256 (константа `MASTER_HASH`).
Чтобы сменить его, посчитайте хеш нового пароля и замените константу.

Состав кода тарифов: ставка ФОТ рабочих, ставка ФОТ технологов, ставка амортизации,
ставка прочих ПР, ставка ОПР (все ₽/сек), коэффициент ОХР и КР, коэффициент % по кредиту, метка версии.

## Логика расчёта

```
подготовка   = время × ставка ФОТ (технолог или рабочий) + время × (амортизация + прочие ПР + ОПР) + материалы
выпуск       = время × ставка ФОТ рабочих + время × (амортизация + прочие ПР + ОПР)
оснастка     = стоимость как есть, без ставок
производственная себестоимость = подготовка + выпуск + материалы + логистика + оснастка
ОХР и КР     = (производственная себестоимость − оснастка) × коэффициент
% по кредиту = производственная себестоимость × коэффициент
полная себестоимость = производственная + ОХР и КР + % по кредиту
цена без НДС = полная себестоимость × (1 + наценка)  либо  целевая цена × партия
```

Скидка применяется к цене без НДС, НДС начисляется на цену после скидки.

## Прочее

* автосохранение расчёта в браузере, кнопка «очистить расчёт»
* предупреждение, если цена оказалась ниже себестоимости
* кнопка «версия для печати / pdf» — чистая раскладка без полей ввода и кнопок

## Как использовать в Tilda

1. создай новый блок Т123 (html-код) на своей странице
2. скопируй всё содержимое файла `index.html`
3. вставь код в блок и опубликуй страницу
